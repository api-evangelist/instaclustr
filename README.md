NetApp Instaclustr is a managed platform for open source data infrastructure, running and supporting Apache Kafka, Kafka Connect, Apache Cassandra, PostgreSQL, OpenSearch, ClickHouse, Valkey and Cadence clusters in its own cloud accounts or in a customer's cloud (Bring Your Own Cloud). Its public Instaclustr API at api.instaclustr.com provides cluster management (provisioning, firewall rules, peering, users, backups, maintenance events), monitoring metrics, user/organization management with SCIM 2.0, and an MCP Gateway product for AI agents. Instaclustr is part of NetApp.

**Areas:** Company · Apache Kafka · Apache Cassandra · PostgreSQL · OpenSearch · ClickHouse · Managed Database · Data Streaming · MCP

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Instaclustr: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
